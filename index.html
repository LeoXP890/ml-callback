Autorização recebida

Esta página não lê, guarda nem envia nada. Ela existe só para o Mercado Livre ter um endereço HTTPS de retorno.

  1. Copie o endereço completo da barra do navegador (começa com https://leoxp890.github.io/ml-callback/?code=).
  2. No terminal do Mac, rode uv run --project apps/api python scripts/ml_oauth_readonly.py finish --authorized e cole quando pedir (a entrada fica oculta).
  3. Feche esta aba. Não envie esse endereço por chat ou e-mail: ele vale por poucos minutos e só funciona uma vez.
